# M0 — Coração

M0 existe para provar o ciclo de vida básico do Soberania no Android sem criar uma falsa sensação de proteção.

## O que já faz

- solicita a autorização de VPN através do diálogo oficial do Android;
- inicia um `VpnService` em primeiro plano;
- cria uma interface TUN IPv4/IPv6;
- mantém notificação de estado;
- encerra e libera a interface corretamente;
- não usa analytics;
- não intercepta HTTPS;
- não adiciona dependências de terceiros.

## Decisão de segurança importante

**M0 não instala rota padrão.**

Ainda não existe um motor de transporte que encaminhe pacotes para a internet. Instalar `0.0.0.0/0` e `::/0` neste momento derrubaria a conexão do usuário e poderia dar a impressão falsa de que o tráfego estava protegido.

Por isso, M0 usa apenas redes reservadas para documentação/teste:

- IPv4: `192.0.2.0/24`
- IPv6: `2001:db8::/32`

Essas rotas serão substituídas por rotas reais somente quando o próximo componente puder encaminhar e proteger pacotes corretamente.

## Always-On

Também permanece desativado no manifesto durante M0.

Só será habilitado quando existir um caminho de dados completo e testado. Um modo Always-On que não encaminha tráfego seria uma excelente maneira de bloquear a internet do aparelho inteiro — portanto não será ativado por aparência.

## Critério para concluir M0

M0 estará concluído quando:

1. o projeto compilar de forma reproduzível;
2. o APK instalar em dispositivo físico;
3. o diálogo de autorização VPN funcionar;
4. a TUN puder ser criada e destruída repetidamente;
5. nenhuma conexão comum do usuário for alterada durante o teste;
6. nenhum SDK de telemetria ou rastreamento estiver presente.
