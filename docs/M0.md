# M0 — Coração

M0 existe para provar o ciclo de vida básico do Soberania no Android sem criar uma falsa sensação de proteção.

## O que já faz

- solicita a autorização de VPN através do diálogo oficial do Android;
- inicia um `VpnService` em primeiro plano;
- cria uma interface TUN IPv4/IPv6;
- mantém ownership explícito do descritor TUN original;
- cria uma duplicata com ownership explícito para um backend de pacote de laboratório;
- passa a duplicata por `PacketRouter -> PacketTunnelBackend`;
- classifica pacotes de laboratório em IPv4, IPv6 ou desconhecidos;
- mantém contadores efêmeros apenas em RAM;
- gera pacotes UDP de teste IPv4 e IPv6 para destinos reservados;
- mantém notificação de estado;
- encerra backend/duplicata antes de fechar a TUN original;
- não usa analytics;
- não intercepta HTTPS;
- não adiciona dependências runtime de terceiros.

## Decisão de segurança importante

**M0 não instala rota padrão.**

Ainda não existe um motor de transporte criptográfico que encaminhe pacotes para a Internet. Instalar `0.0.0.0/0` e `::/0` neste momento derrubaria a conexão do usuário e poderia dar a impressão falsa de que o tráfego estava protegido.

Por isso, M0 usa apenas redes reservadas para documentação/teste:

- IPv4: `192.0.2.0/24`
- IPv6: `2001:db8::/32`

Essas rotas serão substituídas por rotas reais somente quando um backend real puder encaminhar e proteger pacotes corretamente.

## Always-On

Permanece desativado no manifesto durante M0.

Só será habilitado quando existir um caminho de dados completo e testado.

## Teste atual da TUN

O botão de laboratório gera tráfego para:

- IPv4: `192.0.2.1`
- IPv6: `2001:db8::1`

Fluxo atual:

```text
botão de teste
      │
      ▼
UDP IPv4 + IPv6
      │
      ▼
rotas reservadas M0
      │
      ▼
TUN original
      │
      ▼
TunHandle.duplicateOwned()
      │
      ▼
LabPacketRouter
      │
      ▼
LabPacketBackend
      │
      ▼
classificação IPv4 / IPv6
      │
      ▼
contador em RAM
```

O `LabPacketRouter` não fica lendo a TUN no caminho `PACKET_DIRECT`. Ele transfere uma duplicata com ownership explícito ao `PacketTunnelBackend`, reproduzindo o modelo necessário para um backend real de pacote.

Nenhuma métrica é persistida ou enviada.

## Ownership

Regra:

```text
VpnService
   │
   └── dono da TUN original

PacketRouter
   │
   └── cria duplicata

PacketTunnelBackend
   │
   └── recebe ownership da duplicata
```

Ao encerrar:

1. backend fecha a duplicata;
2. router encerra o backend;
3. `VpnService` fecha a TUN original.

## Critério para concluir M0

M0 estará concluído quando:

1. o projeto compilar de forma reproduzível;
2. o APK instalar em dispositivo físico;
3. o diálogo de autorização VPN funcionar;
4. a TUN puder ser criada e destruída repetidamente;
5. o backend de laboratório observar pacotes IPv4 e IPv6 de teste;
6. fechar a duplicata não fechar indevidamente a TUN original;
7. encerrar o serviço liberar backend, duplicata e TUN sem descritores órfãos;
8. nenhuma conexão comum do usuário for alterada durante o teste;
9. nenhum SDK de telemetria ou rastreamento estiver presente.
